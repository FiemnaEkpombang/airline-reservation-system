# Airline Reservation System

A C++ program that manages airline bookings, passenger records, and seat occupancy.

## My Contribution
I was responsible for the Airline class, Flight class, and Passenger header, as well as contributing to main.cpp and file I/O.

## Features
- Add, view, and cancel flights
- Book and cancel reservations
- File-based data persistence
- Input validation

## Technologies Used
- C++
- Vectors
- File I/O
